# SysMonitor Documentation

Version: 2.4.0 | [CoreConduit Consulting Services](https://coreconduit.com)

Unified system monitor for Ubuntu/Debian PCs & servers and Raspberry Pi boards, with local-LLM model-serving detection and hiddenscope-powered security monitoring. See [Overview](overview.md) for what's new.
